# Bookmark Burgle

> Your saved links run a heist against your own browser history.

A local-first web app that treats your bookmarks as vulnerable loot and your browsing session as a crime scene. When you close the tab, thieves steal snippets unless you set traps, pay ransoms, or interrogate the suspects. The dashboard is a tiny detective board, not a normal bookmark manager.

## Features
- Convert saved bookmarks into suspect cards with stolen value scores
- Trigger a nightly heist simulation that marks which links were “robbed”
- Set bait traps on old tabs to catch link thieves in the act
- Recover stolen pages by solving a short clue puzzle from page metadata

## Stack
- Next.js
- SQLite
- Tailwind CSS

## Getting started
```
npm install && npm run dev
```
